## 下次批量下载怎么避免重复

1. 继续从 `E:\TelegramBatchDownloader\TelegramBatchDownloader.exe` 启动，保留原来的整个 `state` 文件夹，恢复同一账号。
2. 确保 F 盘和已关联文件可访问，再扫描同一频道；相同账号、频道、消息与媒体的已完成任务会跳过。
3. 补下现有任务，保持原保存目录，点击“重试失败”，再点“开始 / 继续”。未完成片段会先校验再续传，已完成任务不会被这两个按钮重新下载。
4. 今后再次移动或重命名文件，应更新记录的路径；只移动文件不会自动更新数据库。可使用 MOVED-FILES.md 中的本机辅助脚本。扫描时改变保存目录会让本次涉及的未完成任务在新目录重新下载。
5. 去重针对同一任务；频道用不同消息重复发布的视频仍可能另存。
